# Public template contents

This folder contains fresh-deployment Terraform, placeholder variable/backend examples, provider lock files, static CI, documentation, sanitized test summaries, and a redacted demonstration video/preview. The IP ranges, BGP addresses and ASNs shown in source are reproducible example configuration, not public endpoint addresses or credentials.

No real account/project identifiers, personal email addresses, deployment backend settings, tokens, tunnel PSKs, private keys, state, plans, raw logs, local helpers, provider binaries, original footage, or Git history are included. Supply your own values locally; never commit those generated deployment files.

The video is actual screen capture. Opaque masks remove deployment identifiers and endpoint IPs from its pixels; some apply output is intentionally hidden. Captions, BGP state, tunnel status, and ping samples remain visible.

Publish only this folder as a new repository. The companion private working directory must stay local. Existing repositories and their history have not been inspected or modified by this export.
